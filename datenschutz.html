2. Zweck der App

ImpfPass dient der privaten Dokumentation von Impfungen und der persönlichen Orientierung anhand hinterlegter Empfehlungen der Ständigen Impfkommission (STIKO). Die App ermöglicht die Verwaltung mehrerer Personen, das Erfassen von Impfungen und Terminen, das Speichern von Impfpassfotos und Erinnerungen.

3. Verarbeitete Daten

Je nach Nutzung können Namen, Geburtsdaten, Geschlecht, Impfungen, Impfdaten, Chargennummern, Impfpassfotos und selbst erfasste Termine verarbeitet werden. Diese Angaben werden grundsätzlich im privaten Speicherbereich der App auf dem Gerät gespeichert. Die App erfordert kein Benutzerkonto.

4. Internetverbindung und STIKO-Aktualisierungen

Die App nutzt eine Internetverbindung, um Informationen zu STIKO-Aktualisierungen von GitHub abzurufen. Bei der Verbindung können technisch bedingt die IP-Adresse und weitere Verbindungsdaten an den Server übermittelt werden. Die in der App gespeicherten Personen-, Impf- und Fotodaten werden für diese Aktualisierung nicht an GitHub übertragen. Weitere Informationen zur Verarbeitung von Verbindungsdaten finden sich in den Datenschutzinformationen von GitHub: GitHub-Datenschutzerklärung.

Nutzer können eine ZIP-Datensicherung im Ordner „Download/Impfdaten“ erstellen. Diese kann Personen-, Impf- und Fotodaten enthalten. Die ZIP-Datei ist nicht verschlüsselt. Wer Zugriff auf die Datei erhält, kann die enthaltenen Daten möglicherweise lesen. Vor dem Erstellen der Sicherung erscheint ein entsprechender Bestätigungshinweis. Eine neue Sicherung ersetzt die vorherige Sicherung im vorgesehenen Ordner. Die Wiederherstellung ist nur bei leerem Datenbestand vorgesehen.

Die App-Konfiguration sieht einen Ausschluss der App-Daten von der automatischen Android-Cloud-Sicherung vor. Direkte Geräteübertragungen können je nach Android-Version und Geräteeinstellungen möglich sein. Das Verhalten der Betriebssystemfunktionen liegt nicht vollständig im Einflussbereich der App.

Die in der App gespeicherten Daten bleiben grundsätzlich auf dem Gerät, bis sie gelöscht oder die App-Daten entfernt werden. Bei einer Deinstallation werden private App-Daten normalerweise entfernt. Manuell erstellte ZIP-Sicherungen im Download-Ordner können erhalten bleiben und müssen gegebenenfalls gesondert gelöscht werden.
